
# TechMarket

Учебный проект интернет-магазина электронной и радиоэлектронной продукции.

Проект разработан в рамках дисциплины «Разработка web-приложений».

## Тема проекта

Разработка web-приложения интернет-магазина электронной и радиоэлектронной продукции.

## Используемые технологии

- React и Vite — клиентская часть.
- Node.js и Express — серверная часть.
- PostgreSQL — база данных.
- Docker и Docker Compose — контейнеризация и запуск приложения.

## Запуск приложения с нуля через Docker

### 1. Требования

На компьютере должны быть установлены:

- Git;
- Docker с поддержкой Docker Compose (например, Docker Desktop).

Перед запуском необходимо убедиться, что Docker работает.

### 2. Получение проекта

Открыть терминал и выполнить:

```bash
git clone https://github.com/Pavel-Nesterenko/techmarket-web.git
cd techmarket-web
```

### 3. Сборка и запуск приложения

В корневой папке проекта выполнить:

```bash
docker compose up --build -d
```

Docker Compose автоматически:

- соберёт клиентскую часть React;
- соберёт серверную часть Node.js;
- запустит PostgreSQL;
- создаст таблицы базы данных с помощью `database/schema.sql`;
- добавит начальные товары из `database/seed.sql`;
- запустит все три контейнера.

При первом запуске загрузка образов и сборка могут занять несколько минут.

### 4. Проверка работы

После успешного запуска открыть в браузере:

**Интернет-магазин:**

http://localhost:8080

**Проверка подключения к PostgreSQL:**

http://localhost:3001/api/db-test

Для просмотра состояния контейнеров выполнить:

```bash
docker compose ps
```

Должны работать три сервиса:

- `client` — клиентская часть;
- `server` — серверное API;
- `db` — PostgreSQL.

### 5. Остановка приложения

Для остановки контейнеров выполнить:

```bash
docker compose down
```

Данные PostgreSQL сохраняются в Docker-томе и остаются доступными при следующем запуске.

Для повторного запуска выполнить:

```bash
docker compose up -d
```

## Структура проекта

- `react-app/` — клиентская часть React.
- `server/` — серверная часть Express.
- `database/` — SQL-файлы базы данных.
- `compose.yaml` — конфигурация Docker Compose.
- `README.md` — описание проекта и инструкция запуска.
