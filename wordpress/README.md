
# Практическая работа №9 — WordPress и WooCommerce

## Цель работы
Разработать интернет-магазин TechMarket с использованием CMS WordPress и плагина WooCommerce, настроить каталог товаров, корзину, оформление заказов и личный кабинет покупателя.

## Ход работы

### 1. Установка WordPress
В локальном окружении Local был создан сайт TechMarket на базе WordPress. Выполнена первоначальная настройка сайта и административной панели.

### 2. Установка WooCommerce
Установлен и активирован плагин WooCommerce для реализации функций интернет-магазина.

### 3. Создание каталога
В магазин добавлены три товара:
- Смарт ТВ приставка — 4 990 руб.
- Смарт ТВ приставка Mini — 2 990 руб.
- Цифровой ТВ ресивер — 1 990 руб.

Для товаров указаны названия, цены и изображения.

### 4. Настройка страниц
Настроены страницы Shop, Cart, Checkout и My account. Выполнена настройка навигационного меню сайта.

### 5. Проверка оформления заказа
Проверены добавление товара в корзину, оформление заказа и сохранение информации в WooCommerce.

Создан тестовый заказ №21 на сумму 3 980 руб. Заказ содержит две единицы товара «Цифровой ТВ ресивер».

### 6. Проверка личного кабинета
Проверено отображение оформленного заказа в личном кабинете покупателя.

## Результат
Создан локальный интернет-магазин TechMarket на WordPress с использованием WooCommerce. Проверена работа каталога, корзины, оформления заказов и личного кабинета.

В репозитории размещается описание выполненной работы. Файлы WordPress, база данных и конфиденциальные настройки локального окружения не публикуются.
